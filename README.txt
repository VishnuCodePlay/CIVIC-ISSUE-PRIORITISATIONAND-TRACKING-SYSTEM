CIVIC ISSUE PRIORITISATION SYSTEM — MYSQL VERSION

Setup:
1. Install and start MySQL Server.
2. Run schema.sql in MySQL Workbench or the MySQL command line.
3. Edit DB_CONFIG in civic_issue_system.py; replace YOUR_MYSQL_PASSWORD with your actual password.
4. In Terminal run: python3 -m pip install -r requirements.txt
5. Run: python3 civic_issue_system.py

The app uses MySQL (not SQLite), so a running MySQL Server and valid login are required.
